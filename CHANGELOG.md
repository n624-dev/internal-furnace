## 0.1.0-beta.1 — 2026-09-06

First public beta of Internal Furnace for Minecraft 1.20.1 / Forge 47.4.10 / Java17.

- Seven ranks, 46 individual upgrades, real recipes and up to four chambers.
- Heat, fuel efficiency, queue, output XP and persistent player storage.
- Automatic input/fuel, visual AND/OR rules and M&S equipment protection.
- English/Japanese UI; drag, hotbar/offhand swap and special-item confirmation.
- Both keepInventory modes, read-only administration and exact-JAR handshake.
- MIT source, bilingual documentation, standalone Gradle build and GitHub Actions releases.

The initial public version changes packaging, license and project metadata from the validated development candidate. It preserves the mod ID and player save schema. Older development JARs must be replaced on both sides because the handshake checks the complete JAR hash.
