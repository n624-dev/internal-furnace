# 遊び方

[English](GUIDE.md) · [トップ](../README.ja.md)

## 成長

Vキーまたは`/internalfurnace`で開きます。最初はロックされており、強化タブに購入価格が表示されます。炉心I〜VIIの必要M&S戦闘レベルは**10/20/30/45/60/75/90**です。炉心は購入資格を解放し、性能は個別強化で上げます。購入後に戦闘レベルが下がっても再ロックしません。

素材とバニラXPの**レベル**をサーバーで一括消費します。XP85は85ポイントではなく85レベルです。保護アイテムは購入素材から除外します。[全53行の価格表](../src/main/resources/data/internal_furnace/upgrades.psv)も参照できます。

| 強化 | 初期 → 最大 |
| --- | --- |
| 炉室 | 1 → 4 |
| 速度 | 1倍 → 2倍 |
| 燃費 | 50% → 90% |
| 熱容量 | 1,600 → 51,200 |
| 停止中の放熱 | 基準の100% → 10% |
| 投入キュー | 1 → 27枠 |
| 燃料・出力 | 各1 → 18枠 |

自動投入強化の残響の欠片は合計4個。Mowzie's MobsのIce Crystalは断熱の最終強化だけで1個消費します。

## 6タブと操作

- **投入:** レシピのあるアイテムを予約します。解放後は選択枠を矢印・先頭・末尾で並べ替えできます。枠の停止はキューIVで解放。炉室の×は、空きがあれば入力をキューに戻します。
- **燃料:** 有効な燃料を入れます。燃料1個分の熱が収まらない場合は消費しません。
- **出力:** 完成品と対応するXPを取り出します。外からの投入はできません。
- **強化:** 価格を確認し、炉心・個別強化を購入します。
- **自動化:** 自動投入・自動燃料を設定します。初期OFFで、明示した条件から始めます。
- **統計:** 処理数や燃料消費数を確認します。

左右クリック、Shiftクリック、左右ドラッグ分配、数字キー交換、オフハンド交換、ダブルクリック回収、Qでの取り出しに対応します。未解放・非表示の枠は使えません。出力XPは実際に取り出した個数に応じて一度だけ精算します。

名前・エンチャント・損傷・M&Sデータ等のある装備は、精錬により追加データを失う場合があります。特殊装備の手動投入では結果を表示した確認が必要です。確認は現在のアイテム・移動先・レシピに紐付き、期限があります。条件が変われば確認し直します。保護済み装備はレシピがあっても拒否します。「手持ちを保護」で体内かまど用の保護フラグを切り替えます。

## レシピと熱

炉心IIIで燻製・溶鉱を解放し、溶鉱→燻製→通常精錬の順に適合するレシピを選びます。結果はMinecraftのRecipeManagerに従い、独自の追加回収報酬は作りません。

燃料は共通の熱量に変換します。標準200tickの精錬は200 heat、標準100tickの燻製・溶鉱も200 heatです。速度や炉室数を増やしても必要な熱は減りません。燃費は購入した段階に従い、バニラの90%が上限です。

バケツ等の残る容器にも空きが必要です。熱や容器が収まらなければ燃料を消費しません。全炉室が進行しないときは設定値に従って放熱し、手動停止中も冷えます。ログアウト中・サーバー停止中は進行も放熱もしません。

## 自動化

通常インベントリ9〜35番を走査し、ホットバー・防具・オフハンドは対象外です。他のコンテナを開いている間は停止します。満杯なら元の所持品を維持します。自動投入I〜VでアイテムID、カテゴリ、詳細条件、M&Sレアリティ/装備レベル、一般AND/ORを順次解放。自動燃料I〜IVは補充、優先順、しきい値、需要予測を追加します。

画面で新規ルールを作ると初期値は**PROTECT（保護）**です。「設定を送信」するまで下書きで、破棄/Escapeでは保存済み設定を変えません。サイズ変更でも下書きを保持します。ルール・ORグループ・AND条件を選び、条件と値を編集します。「手持ちから取得」で実際の属性をコピーできます。消費したい対象だけINPUTに変更し、自動投入を明示的にONにします。

PROTECTは順序に関係なくINPUTより優先します。不明なM&Sデータは保護します。IVは明示的なレアリティと装備レベル上限、VはM&Sの安全条件を維持した一般複合条件に対応します。JSONと上限は[設定](CONFIGURATION.ja.md)を参照してください。

## 保存と死亡

炉心・強化・アイテム・進行・熱・設定・未精算XPをプレイヤーへ保存します。

- `keepInventory=true`: 死亡後も内部アイテムと状態を保持します。
- `keepInventory=false`: 内部アイテムを一度だけドロップし、熱と未精算XPを消去。炉心・強化は維持します。

破損・未知の保存形式は勝手に初期化せず隔離します。レシピ変更で互換性のない進行は無効にし、入力は回収可能な状態で保持します。復旧エラー時はプレイヤーデータを編集する前に原因を調べてください。

権限2の管理者は`/internalfurnace admin open <player>`で他人を閲覧専用表示できます。`setrank <player> <0-7>`、`setupgrade <player> <track> <level>`は上昇のみ。`reset <player> CONFIRM`は中身を返し、隔離データを破棄しません。
