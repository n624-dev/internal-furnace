# Internal Furnace 0.1.0-beta.1

## English

First public beta: an upgradeable player-owned furnace built around Mine and Slash progression. Includes four-chamber processing, shared heat, 53 purchases, visual automation rules, equipment protection and English/Japanese UI.

**Required:** Minecraft 1.20.1, Forge 47.4.10, Java17, Mine and Slash 6.4.7, Library of Exile 2.1.11, Mowzie's Mobs 1.8.2 and their dependencies. Install the **same JAR on both client and server**. Dependencies are not bundled. Back up an existing world before adopting a beta.

Download `internal-furnace-0.1.0-beta.1.jar`. `SHA256SUMS` is the checksum file; GitHub's automatically generated source archives are not installable MODs. Open with V or `/internalfurnace`.

Core/editor/drag tests, Forge builds and disposable dedicated-server/graphical-client tests cover the implemented scenarios. Beta status reflects remaining broader compatibility and long-term balance evaluation. See the repository's verification report for exact scope. MIT licensed; no automatic server deployment or CurseForge upload.
